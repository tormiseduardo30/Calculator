# JavaScript Calculator

A simple calculator built with HTML, CSS, and JavaScript. This project was created to practice frontend web development, DOM manipulation, event handling, and basic calculation logic.

## Features

* Perform basic arithmetic calculations
* Interactive calculator buttons
* Responsive and clean user interface
* JavaScript-powered calculation logic
* Keyboard input support (if implemented in the current version)

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

```text
calculator/
├── calculator-final.html
├── calculator.css
├── calculator.js
└── README.md
```

## Getting Started

1. Clone or download this repository.
2. Open `calculator-final.html` in your web browser.
3. Start using the calculator.

No additional packages or installation are required.
